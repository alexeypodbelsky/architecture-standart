### <a name="_qmphm5d6rvi3"></a>**Решение**
Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения. 

Также опишите, какой логикой вы руководствовались в ходе принятия решений и выбора технологий. Не забывайте, что необходимо учесть все функциональные и нефункциональные требования.

- Диаграмма контекста C4 преведена в файле "С4_Context". 
- Диаграмма контейнеров C4 приведена в файле "C4_Container" 

В настоящее время процесс управления ставками в банке "Стандарт" не автоматизирован. Обмен информацией о ставках происходит вручную через электронную почту, с использованием Excel-файлов. Это приводит к задержкам в обновлении информации и недоступности актуальных ставок для сотрудников колл-центра. Маркетинговая кампания, направленная на привлечение новых клиентов, может привести к резкому увеличению количества обращений в колл-центр, в том числе от пожилых клиентов, которым потребуется консультация по условиям открытия депозита. Партнерский колл-центр также нуждается в актуальной информации о ставках, но может получать ее только через SFTP в виде Excel-файлов.

Решение:
Внедрить новый сервис управления ставками для централизованного хранения и управления информацией о ставках. Сервис будет предоставлять API для доступа к данным о ставках и интерфейс для обновления информации сотрудниками бэк-офиса.

Решение даст следующие преимущества:
- Информация о ставках хранится в одном месте, что обеспечивает консистентность данных.
- Сотрудники колл-центра и партнерского колл-центра всегда имеют доступ к актуальным ставкам.
- Автоматизация процесса обновления ставок снижает трудозатраты и вероятность ошибок.
- Новый сервис позволит легко добавлять новые типы ставок и каналы распространения информации.

Недостатки:
- Необходимость разработки и внедрения нового сервиса.
- Необходимость интеграции с существующими системами (колл-центр).
- Затраты на разработку, тестирование и поддержку нового сервиса.

Технологии:
- Бэкенд: PHP (В соответствии с +R2)
- Фронтенд (для бэк-офиса): React
- База данных: MS SQL Server (В соответствии с +R2)
- API: RESTful API
- SFTP: Использование существующего SFTP-сервера банка.

Интеграция:
- Система колл-центра банка будет интегрирована с сервисом управляения сатвками через RESTful API для получения информации о ставках (требование F1).
- Система управления ставками будет автоматически выгружать файл с информацией о ставках на SFTP-сервер для партнерского колл-центра (требования F2 и +R1). Файл будет в формате Excel, соответствующем существующему формату (+R3).
- Бэк-офис будет использовать веб-интерфейс системы управления ставками для загрузки и обновления информации о ставках (требование F3).
